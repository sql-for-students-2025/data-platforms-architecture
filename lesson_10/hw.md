### Реализация заливки справочников через stage-слой с использованием функционала подмены таблицы

1. Смена движка. Если Вы при выполнении предыдущего ДЗ вы использовали таблицы ReplacingMergeTree, то Вам необходимо изменить движок на MergeTree. 
2. Создание stage-слоя. Необходимо для каждой таблицы `<your_login>_db.dim_...` создать ее копию с постфиксом stage (`<your_login>_db.dim_..._stage`). Для упрощения создания можно использовать код `show table <your_login>_db.dim_...`, этот запрос вернет вам код таблицы без лишних движений. 
3. Корректировка кода. Необходимо ваш код, который вы писали для предыдущего занятия доработать таким образом, чтоб поток осуществлял следующие действия:
    - Получение данных из RabbitMQ
    - Заливка полученных данных в S3
    - Заливка данных из S3 в stage-таблицы Clickhouse с использованием функции `Insert into some_tabl ... select fields from function s3()` с использованием именованной коллекции, а не access_key и secret_key
    - Подмена stage (`dim_..._stage`) и prod (`dim_...`) таблиц
    - Очистка stage таблиц
    - Проверка справочников на дубликаты с выводом в логи соответствующего сообщения.
