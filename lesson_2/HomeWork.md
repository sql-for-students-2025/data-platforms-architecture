**Задание: «Разобрать путь одного набора данных»**

Необходимо выбрать один конкретный набор данных из кейса ритейла, например:

* продажи;
* остатки;
* заказы интернет-магазина;
* клиенты программы лояльности.

И описать его путь:

| Вопрос                          | Что нужно указать                 |
| ------------------------------- | --------------------------------- |
| Где данные возникают?           | конкретная бизнес-система         |
| Что является источником истины? | System of Record                  |
| Как данные забираются?          | batch / API / events / CDC        |
| Где оказываются сначала?        | PostgreSQL / S3 / RabbitMQ и т.д. |
| Где трансформируются?           | Airflow / SQL / Python            |
| Где хранятся для аналитики?     | ClickHouse                        |
| Кто потребляет?                 | BI / аналитик / ML / приложение   |
| Какая нужна свежесть?           | например, ≤ 15 минут              |
| Что может сломаться?            | 3–5 рисков                        |
| Как контролировать качество?    | 2–3 проверки                      |
