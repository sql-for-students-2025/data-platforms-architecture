### Папка для размещения дагов студентов. 

```

└── students_dags
    └── Readme.md

```

Правила создания дага:
1. Создаете папку с вашим ником (ivanov_ii)
2. В папке с ником под каждый даг вы создаете свою папку с использованием следующего вида наименования {первые буквы каждого слова каталога первого уровня}_..._{первые буквы каждого слова каталога N-го уровня}_имя_дага
3. Наименование файла дага это имя из п.2 с расширением .py
4. Имя дага в файле (dag_id) это имя из п.2 

Например:
Студент Иванов И.И. в своей папке создал даг homework_9, тогда дерево каталога будет выглядеть следующим образом

```
└── students_dags
    └── Readme.md
    └── ivanov_ii
        └── sd_iii_homework_9
            ├── sd_iii_homework_9.py
            └── subtask_scripts
                └── subtask_from_folder.py
```
